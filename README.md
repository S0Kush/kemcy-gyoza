# Kemcy — Gyoza

Mini-jeu de plateforme pour le morceau **Gyoza** de Kemcy : rattrape le grapheur qui a tagué la vitrine du local, à travers les toits.

**Jouer :** https://s0kush.github.io/kemcy-gyoza/

- Clavier : ← → / Q D pour courir, Espace / ↑ / Z pour sauter, P pause, R recommencer, M son
- Mobile : boutons à l'écran, téléphone à l'horizontale

Un seul fichier (`index.html`), HTML/CSS/JavaScript sans dépendance. Pour ajouter la musique, déposer `gyoza.mp3` à côté de `index.html` et régler le `bpm` dans `CONFIG`.
